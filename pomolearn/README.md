# Pomolearn 🍅📚

This directory contains the main source code for the Pomolearn application. For more information, please check the [README](../../README.md) file at the project root.

## 🚀 Features

- **4 distinct 25-minute study cycles** generated by AI.
- **25-question MCQ quiz** for assessments.
- **Clean and focused interface** for uninterrupted learning.
- Powered by **Google Gemini 2.5 Flash**.

## 🏃 How to Run

1.  Navigate to this directory in your terminal.
2.  Install dependencies: `npm install`
3.  Configure your API key in a `.env` file (see `.env.example`).
4.  Run the server: `node server.js`
5.  Open `http://localhost:3000` in your browser.
